# Security Policy

## Supported versions

Cobra is in early development. Security updates, when needed, will be applied
to the current development branch and back-ported to the most recent release
tag at the project owner's discretion.

## Reporting a vulnerability

Please report security vulnerabilities privately. Do not open a public issue
for a vulnerability.

Contact: **security@cobra-project.dev** [PLACEHOLDER — security contact email
is pending owner input; see the Human-input queue in
`orchestration/STATE.md`].

When reporting, please include:

* a description of the issue,
* the affected component and version or commit,
* steps to reproduce or a proof of concept,
* expected and observed impact.

The project owner will acknowledge receipt as soon as practical, investigate,
and coordinate a fix and disclosure timeline.

## Disclosure policy

We prefer coordinated disclosure. Once a fix is available and affected parties
have had reasonable time to update, we will publish a security advisory and
credit the reporter unless they request otherwise.
